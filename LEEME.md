# Сайт-витрина Ritmo OPS

Статический сайт: только HTML, CSS и картинки. Никаких сборок и зависимостей.

## Файлы

- `index.html` — главная (испанский)
- `restaurantes.html` — страница под рестораны
- `comercio.html` — страница под торговлю и склады
- `ru/index.html`, `en/index.html` — версии главной
- `privacidad.html` — конфиденциальность и aviso legal (заполнить реквизиты!)
- `style.css` — один файл стилей на все страницы
- `img/` — логотип, скриншоты программы, картинка для соцсетей
- `robots.txt`, `sitemap.xml` — для поисковиков
- `CNAME` — домен для GitHub Pages

## Перед публикацией

1. **Домен.** Везде прописан `ritmo-ops.com`. Если купите другой — замените во всех файлах:
   в macOS/Linux `grep -rl 'ritmo-ops.com' . | xargs sed -i 's/ritmo-ops\.com/ВАШ-ДОМЕН/g'`,
   в Windows проще открыть файлы в «Блокноте» и заменить через Ctrl+H. Не забудьте `CNAME`.
2. **Почта.** Сейчас везде `hola@ritmo-ops.com`. Заведите этот ящик у регистратора домена
   (обычно бесплатная пересылка на вашу личную почту) или замените на свой адрес.
3. **Реквизиты** в `privacidad.html`: razón social, NIF, адрес.
4. По желанию — WhatsApp: добавьте рядом с кнопкой почты ссылку
   `https://wa.me/34XXXXXXXXX?text=Hola%2C%20quiero%20una%20demo`.

## Как выложить (GitHub Pages, бесплатно)

1. Создайте репозиторий `ritmo-site`, загрузите туда все файлы из этой папки.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Там же Custom domain: ваш домен → Save. Поставьте галочку «Enforce HTTPS».
4. У регистратора домена в DNS добавьте:
   - `A` для `@`: 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153
   - `CNAME` для `www`: `ВАШ-ЛОГИН.github.io`
   - `CNAME` для `app`: адрес приложения в Railway (потом в Railway → Settings → Custom Domain
     добавьте `app.ВАШ-ДОМЕН`)
5. Через 10–30 минут сайт откроется по домену с сертификатом.

## После публикации

1. Google Search Console → добавить ресурс (Domain), подтвердить TXT-записью в DNS,
   отправить `sitemap.xml`. Обычно за 3–10 дней сайт начинает находиться по запросу «Ritmo OPS».
2. Bing Webmaster Tools — то же самое, там импорт из Search Console в один клик.
3. Закрыть приложение от индексации: в Ritmo OPS отдаётся страница входа, и её в поиске быть
   не должно. Скажите мне — добавлю в приложение `robots.txt` с `Disallow: /`.
4. Каталоги: Capterra, GetApp, Software Advice — бесплатная регистрация продукта.
