# Ritmo OPS Showcase — static prototype

Файлы: `index.html`, `styles.css`, `script.js`.

Включено: премиальная молочно-графитовая палитра с шалфейным и бронзовым акцентом, анимированные демо-KPI, SVG-график, переключаемые отраслевые демонстрации (beauty, рестораны, услуги, розница, корпоративный бизнес), галерея CRM/ERP/автоматизации и отдельный блок онлайн-сервиса накладных по подписке.

## Важно перед публикацией
- Это статический прототип витрины. Сервис накладных показан как продукт по подписке, но реальная загрузка, авторизация, тарифы, биллинг и обработка документов не подключены этим макетом.
- Форма заявки пока демонстрационная и не отправляет данные. Подключите backend/email/CRM до публикации.
- Метрики и примеры помечены DEMO; не выдавайте их за реальные показатели клиентов.
- Языковые переключатели и полноценные ES/EN переводы в этой версии не реализованы.
- Перед заливкой на существующий сайт проверьте стек, маршруты, Git-изменения и конфигурацию публикации; не перезаписывайте проект вслепую.
