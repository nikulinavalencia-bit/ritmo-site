# Ritmo OPS website redesign

Updated the three-language landing pages (Spanish `/`, Russian `/ru.html`, English `/en.html`) to position Ritmo OPS as a business automation and systems implementation partner, while retaining the delivery-note/invoice intake product and the existing application URL.

Included:
- service areas: process automation, CRM, ERP/operations, dashboards, integrations, custom platforms;
- interactive sample dashboard tabs for operations, finance, inventory and sales;
- clearly labelled fictional sample data;
- email contact retained: ritmoops@gmail.com;
- app link retained: https://app.ritmo-ops.com;
- responsive styles and language navigation.

The dashboard is a front-end illustrative demo only. It is not connected to customer data or a live ERP.
